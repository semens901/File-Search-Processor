# FSP — File Search Processor

# РУССКАЯ ВЕРСИЯ

Назначение:
Многопоточная CLI-утилита под Linux для поиска заданного текста
в файлах файловой системы.

Язык:
C++20

Платформа:
Linux

Система сборки:
CMake

Тестирование:
Catch2

# ОСНОВНАЯ МОДЕЛЬ МНОГОПОТОЧНОСТИ

Producer:
Directory Scanner

Task Queue:
Потокобезопасная очередь, содержащая задачи
обработки файлов.

Consumers:
Worker-потоки из Thread Pool.

Worker:
Получает задачу
↓
Читает файл
↓
Выполняет поиск pattern
↓
Формирует результат
↓
Обновляет статистику

# MVP

Команда:

```
fsp <pattern> <path>
```

Пример:

```
fsp "ERROR" ./logs
```

С указанием количества потоков:

```
fsp "ERROR" ./logs --threads 8
```

# ТРЕБОВАНИЯ MVP

1. Рекурсивный обход директорий.
2. Обработка обычных файлов.
3. Поиск заданной строки.
4. Использование нескольких worker-потоков.
5. Потокобезопасная очередь задач.
6. Реализация модели Producer/Consumer.
7. Настраиваемое количество worker-потоков.
8. Вывод результатов поиска.
9. Обработка ошибок файловой системы.
10. Корректное завершение потоков.
11. Unit-тесты.
12. Integration-тесты.

# CORE CONCURRENCY MODEL

Producer:
Directory Scanner

Task Queue:
A thread-safe queue containing file processing tasks.

Consumers:
Worker threads from the Thread Pool.

Worker:
Receives a task
↓
Reads the file
↓
Searches for the specified pattern
↓
Produces a search result
↓
Updates statistics

# MVP

Command:

```
fsp <pattern> <path>
```

Example:

```
fsp "ERROR" ./logs
```

Specify the number of worker threads:

```
fsp "ERROR" ./logs --threads 8
```
